Methodology & data

  • Cost is the measured billed cost per Intelligence Index task including input, reasoning and answer tokens — not a per-token price.
  • Speed is the measured end-to-end time per task (output speed, time to first token, reasoning length and provider queueing combined). Archive-era times are the latest in-era dated measurements from the upstream history (hover/table show each observation date); they are sparse and not synchronized to the snapshot date, and throughput was never recorded for those rows.
  • Index eras are incomparable: scores and costs measured under different index compositions are never mixed — pick one era above.
  • The green “Preferred corner” box marks the cheaper/faster/smarter octant of the full era range (split at the scale midpoint for cost and speed — geometric on log axes, arithmetic on linear — mid-range for intelligence) — a relative guide, not an optimum. It disappears when the full era range collapses.
  • Data: Artificial Analysis measurements via the CatalystNeuro LLM Frontier updater (methodology, code, BSD-3-Clause). Upstream data is governed by Artificial Analysis terms. See README for limits.
  • Contributor (always on) adds separately labeled estimate points next to the measured ones: Meta Muse Spark Contributor repricing for Muse Spark 1.3 (xhigh) and 1.2 (xhigh) — Standard rates $0.15/$1.25/$4.25 perM vs Contributor $0.002/$0.10/$0.20 (cached/input/output), blended at an assumed 7:2:1 mix (.0414/.78, no per-task token counts published). Estimates inherit benchmark intelligence/speed (not provider-measured, never called measured). Contributor pricing allows training use; Muse Spark (max) is Standard-only and stays measured-only.
